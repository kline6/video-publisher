# Phase 4: AI 集成设计

## AI 功能概览

### 1. 视频脚本生成
- **输入**: 主题、风格（干货/故事/快节奏）、时长、目标平台
- **输出**: JSON 结构化脚本（标题、开场钩子、分段内容、行动号召）
- **模型**: OpenAI GPT-4o（可配置为国内大模型）
- **Prompt 工程**: 根据风格注入不同的 system prompt

### 2. 标题优化
- **技巧**: 数字法、悬念法、好奇心法、emoji 增强
- **输出**: 可配置数量的标题数组
- **解析**: 先尝试 JSON 数组解析，降级到按行分割

### 3. 标签生成
- **分类**: 核心关键词、长尾关键词、热门话题、平台专属
- **输出**: 10-15 个标签

### 4. 视频描述
- **结构**: 概括 + 要点列表 + emoji + 标签 + CTA

### 5. 封面提示词
- **输出**: Midjourney / DALL-E 风格的英文提示词
- **包含**: 风格、色彩、构图、文字空间描述

## 成本控制
- 所有 AI 调用记录 tokens_used
- 历史记录可查看，便于成本分析
- 建议在 OpenAI 账户设置月度预算上限

## 扩展方案
- 如需切换为国内大模型（如文心一言、通义千问），只需修改 `config.openai.baseUrl` 和 `config.openai.model`
- OpenAI SDK 的 `baseURL` 参数兼容大多数 OpenAI-compatible API
