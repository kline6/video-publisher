# Phase 3: 前端页面设计

## 页面路由

| 路径 | 页面 | 描述 |
|------|------|------|
| `/login` | 登录页 | 用户登录 |
| `/register` | 注册页 | 用户注册 |
| `/dashboard` | 数据看板 | 概览统计、平台分布、30 天趋势 |
| `/publish` | 视频发布 | 任务列表、新建发布、AI 辅助 |
| `/accounts` | 账号管理 | 绑定/解绑各平台 OAuth 账号 |
| `/calendar` | 内容日历 | 可视化排期、创建计划 |
| `/traffic` | 流量实验室 | 热门话题、最佳发布时间、流量攻略 |
| `/ai` | AI 助手 | 脚本生成、标题优化、标签生成、封面提示词 |

## UI 设计原则

1. **布局**: 左侧可折叠导航栏 + 顶部用户栏 + 内容区域
2. **配色**: 蓝色主色 (#3B82F6)，绿色辅助 (#10B981)，紫色点缀 (#8B5CF6)
3. **响应式**: 使用 Ant Design 的 Grid 系统 (Row/Col)
4. **交互**: 所有异步操作有 loading 状态，操作反馈用 react-hot-toast

## 关键交互

### 视频发布流程
1. 点击"新建发布"打开 Modal
2. 填写视频简介/主题
3. 点击"✨ AI"按钮自动生成标题/标签
4. 选择发布平台（多选）
5. 设置定时发布（可选）
6. 提交后进入任务队列

### AI 助手使用流程
1. 选择工具类型（脚本/标题/标签/封面提示词）
2. 填写参数
3. 点击生成，等待 AI 返回
4. 复制结果到剪贴板或直接应用到发布任务
